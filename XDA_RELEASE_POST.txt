===========================
  Introduction
===========================
This is an unofficial, work-in-progress port of LineageOS 23 (Android 16)
to the Nothing Phone (3), codename "metroid" (Qualcomm SM8735).

This release is a release-key-signed full Virtual A/B OTA installed through
Lineage Recovery. The payload includes the complete boot/AVB chain, pvmfw,
dynamic partitions, recovery, and DLKM images. It has passed offline payload
and AVB verification. Device validation status must be copied from the final
test report before this post goes live.

===========================
  Installation
===========================
PREREQUISITES
- Unlocked bootloader.
- Current Google platform-tools (`adb` and `fastboot`).
- Nothing OS B4.1 (`Metroid_B4.1-260414-1846`) firmware. This ROM does not
  redistribute modem/bootloader firmware. Restore/update stock first if needed.
- A complete stock restore package and a known-good recovery procedure.
- The ROM ZIP and the matching metroid Lineage Recovery bootstrap bundle from
  the same release. Do not mix artifacts from different builds.

IMPORTANT device-specific notes (please read):
- Do NOT use `--disable-verity` or `--disable-verification` on root vbmeta.
- Do NOT manually force an OTA target slot. Update Engine selects it.
- `fastboot boot` is not supported on this device. Flash the matched bootstrap
  bundle, then reboot to recovery.
- The bootstrap installer writes the matched boot, init_boot, vendor_boot,
  dtbo, pvmfw, recovery, and vbmeta chain to both slots. Review the included
  script before running it.

CLEAN INSTALL FROM LINEAGE RECOVERY
1. Back up everything. Unlocking/factory reset erases apps, accounts, settings,
   encryption metadata, and internal storage.
2. Extract the matching recovery bootstrap bundle on your computer.
3. Reboot to bootloader:
       adb reboot bootloader
4. Verify the serial with `fastboot devices`, then run the included script:
       Windows:  flash-lineage-recovery.bat
       Linux:    ./flash-lineage-recovery.sh
   The script does not disable AVB. It flashes the matched chain to both slots,
   clears only the stale recovery BCB in `misc`, and reboots to Lineage Recovery.
5. In Lineage Recovery select:
       Factory reset -> Format data / factory reset
6. Return to the main menu and select:
       Apply update -> Apply from ADB
7. On the computer run:
       adb sideload lineage-23.0-20260731-UNOFFICIAL-metroid.zip
   The host often stops near 47% for an A/B OTA; this is normal. Wait for the
   phone to report installation success. Do not disconnect it during device-side
   verification or postinstall.
8. If recovery asks about installing additional packages, choose No for the
   first test. Untested add-ons can obscure ROM defects.
9. Select Reboot system now. Allow up to about 8 minutes for first boot.

UPDATING FROM AN EARLIER BUILD SIGNED WITH THE SAME RELEASE KEY
1. Reboot to Lineage Recovery.
2. Apply update -> Apply from ADB.
3. `adb sideload <new ZIP>`.
4. Do not factory reset unless the release notes require it.

If recovery or Android fails, stop and collect logs before changing slots. Use
the documented stock restore path; do not repeatedly flash random vbmeta flags.


===========================
  How to build from source
===========================
Full device tree + framework patches are on GitHub (link below).
- Sync a LineageOS 23 tree.
- Add the metroid device tree + a local manifest (see repo README).
- Extract proprietary blobs from your own device (extract-files.sh) — blobs
  are NOT redistributed.
- Apply the two frameworks/base patches in patches/.
- lunch lineage_metroid-bp2a-userdebug && m bacon

A complete "how it was brought up" guide (every fix + the debugging method)
is in the repo: BRINGUP_GUIDE.md.

===========================
  Known bugs / reporting
===========================
When reporting a bug include the exact ZIP SHA-256, clean/upgrade install,
firmware version, reproduction steps, and logs:
  adb logcat -b all -d > logcat.txt
  adb shell dmesg > dmesg.txt
Do not report issues after installing an unlisted kernel, root module, or add-on
without reproducing on the clean ROM first.
