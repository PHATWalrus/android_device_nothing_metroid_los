INSTALL / UPDATE
1. Use the matching Lineage Recovery/bootstrap for this release.
2. In recovery choose Apply update -> Apply from ADB.
3. Run:
     adb sideload lineage-23.0-20260804-UNOFFICIAL-metroid.zip
4. The host commonly stops near 47 percent for A/B OTAs; wait for recovery.
5. Do not disable AVB/verity and do not manually force an OTA target slot.
